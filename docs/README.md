# Research Email Automation

A **localhost-only**, **single-user**, **no-database** tool for sending
personalized cold emails to research professors for internship inquiries.

- ~85–90% of every email is a fixed template **you** control.
- Only the **2–3 personalized sentences** are generated by Gemini Flash.
- All data lives inside the project folder as plain **JSON + Excel** files.
- Copy the folder anywhere, run `npm install && npm run dev`, and you're back
  in business.

---

## Features

- Bulk-import professors from Excel (`.xlsx`)
- AI-generated 2–3 sentence personalization per professor (Gemini Flash)
- Editable subject + body per professor before sending
- Resume PDF auto-attached to every email
- Gmail SMTP sending with configurable delay between emails
- Retry failed emails with one click
- Local Settings UI (no `.env` editing required)
- **Test Configuration** button — verifies Gemini key, SMTP, resume, Excel
  parser in one click
- Logs page — sent history, failed history, errors log, app log
- 100% portable — zero database, zero servers, zero cloud

## Tech stack

| Layer          | Choice                             |
| -------------- | ---------------------------------- |
| Framework      | Next.js 14 (App Router) + TS       |
| Styling        | Tailwind CSS + shadcn/ui-style    |
| Storage        | Plain files in `data/` (JSON + xlsx) |
| AI             | Google Gemini (`gemini-2.5-flash` default; configurable) |
| Email          | Nodemailer + Gmail SMTP            |
| Excel parsing  | `xlsx`                             |

> **No database. No Prisma. No Redis. No Docker. No auth.** This is a
> single-user localhost productivity tool, intentionally kept tiny.

## Setup (first-time)

> Requires **Node.js >= 18.18** (Node 20 LTS recommended). Get it from
> <https://nodejs.org>. `npm` ships with Node.

```bash
npm install
npm run setup     # creates data/, uploads/, logs/, sample Excel
npm run dev
```

Open <http://localhost:3000>.

Then in the UI:

1. **Settings → AI**: paste your Gemini API key
2. **Settings → Email**: enter Gmail + 16-char App Password
3. **Settings → Resume**: upload your PDF
4. Click **Test Configuration** at the top — make sure all four checks pass:
   - ✅ Gemini API
   - ✅ Gmail SMTP
   - ✅ Resume file
   - ✅ Excel parser

See [ENV_SETUP.md](./ENV_SETUP.md) for how to obtain the Gemini key and
Gmail App Password.

## Daily workflow

1. **/professors → Upload .xlsx** — bulk-import your professor list.
2. **Select rows → Personalize selected** — Gemini generates 2–3 sentences
   for each, cached so repeats are free.
3. Click the eye icon to **preview & edit** any draft.
4. **Send selected** — emails go out one at a time with the delay you set in
   Settings → Sending. Resume PDF is attached automatically.
5. **/logs** — see what was sent, what failed, and why.

Required columns (case-insensitive):

| professor_name | university | email |

Optional columns:

| lab_website | department | research_area | notes |

Download the working template from the Professors page (or
`/SAMPLE_EXCEL_FORMAT.xlsx`).
